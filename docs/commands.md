# 指令列表

## 关于唤醒前缀

`/` 只是 AstrBot 的出厂默认唤醒前缀。你可以在 AstrBot 设置里把它改成 `!`、`#`、`.`，也可以整个清空（清空后直接发 `mp status`）。本文档一律按默认的 `/` 书写，请自行替换成你实际用的那个；私聊或者 @机器人 的场合本来就不需要前缀。

不确定自己的前缀是哪个？插件所有回复里的命令示例都会按**你实际生效的前缀**渲染，照抄回复里的写法就行。发一次 `/mp help`，它会按真实前缀把整份子命令清单重新打印一遍。

## 三种等价写法

```
/mp status
/magpie status
/神偷 status
```

`mp` 是主命令组（meme + pilfer，两个字母好敲），`magpie` 是早期名称留下的别名，`神偷` 是中文别名，三者完全等价。

指令组是 `mp`，别名 `magpie` 和 `神偷`。下表只写子命令，实际发送时记得带上你的唤醒前缀，例如 `/mp status`（默认前缀）或 `!mp status`（把前缀改成 `!` 的情况）。

## 所有人可用

| 指令 | 说明 |
|:---|:---|
| `status` | 运行状态和表情包统计 |
| `list [分类] [每页数量] [页码]` | 列出已收集的表情包（默认每页 10 张，页码从 1 开始） |
| `emotion_stats` | 情绪分析统计和当前模式 |
| `help` / `帮助` | 按你当前的唤醒前缀打印完整子命令清单 |

## 仅管理员

| 指令 | 说明 |
|:---|:---|
| `on` / `off` | 开启 / 关闭表情包收集 |
| `auto_on` / `auto_off` | 开启 / 关闭自动发送 |
| `偷` | 进入 30 秒强制收录模式，期间发的图片一律收下 |
| `natural_analysis <on\|off>` | 切换两套情绪识别模式 |
| `clear_emotion_cache` | 清空情绪分析缓存 |
| `delete <序号\|文件名>` | 删除表情包 |
| `blacklist <序号\|文件名>` | 删除并加入黑名单，之后不再重复收录 |
| `scope <序号\|文件名> <public\|local>` | 设置作用域，`local` 只允许在来源群发送 |
| `clean` | 清空 `raw` 暂存目录里还没入库的原始图，已入库的表情包不受影响 |
| `capacity` | 立即执行一次容量上限清理，**会永久删除超出上限的最旧表情包**（收藏的不删；只想看容量用 `status`） |
| `tag_stats [N]` | 标签体检：高频标签、低频噪声标签、零标签条目（N 默认 15） |
| `rebuild_index` | 重建检索索引（版本迁移或索引异常时用），只重建索引，**不会删图** |
| `rebuild_vectors` | 清空并重建语义检索向量。改过描述、但搜出来还是旧内容时用；没配嵌入模型会直接提示不需要 |
| `migrate [check\|apply\|move] [路径]` | 从 astrbot_plugin_stealer 迁移数据 |
| `group show` | 查看收 / 发名单配置 |
| `group <send\|steal> priority <wl\|bl>` | 设置白黑名单冲突时的优先级 |
| `group <send\|steal> <wl\|bl> <add\|del\|clear> [group:群号\|user:QQ号]` | 管理黑白名单 |
